### 이 회차에 발견해 수정한 결함

| # | 증상 | 원인 |
|---|------|------|
| 1 | 자정 이후 편성이 목록에서 사라짐 | API가 `24:54:00` 처럼 24시 이상으로 표기하는데 `HH`는 0~23만 받아 파싱 실패 → null로 버려졌다 (잠실 평일 상행 239편 중 4편) |
| 2 | 00시대에 "곧 도착"이 5시간 뒤 열차를 가리킴 | 목록 순서대로 앞에서 골라, 1분 뒤 도착하는 24:21 편성 대신 05:40 편성이 잡혔다. 남은 시간 짧은 순으로 정렬해 해결 |
| 3 | 남은 시간이 갱신되지 않음 | 조회 시점에 한 번만 계산. 열차가 지나가도 목록에 남아 있었다 |
| 4 | 응답 대기에 상한이 없음 | `DocumentBuilderFactory.parse(url)` 은 `URL.openStream()` 을 쓰고 기본 타임아웃이 없다. 서버가 응답을 멈추면 로딩 표시가 사라지지 않는다 |
| 5 | 저장 목록 배지가 항상 초록 | 행 그림(`line2.jpg`)에 2호선 초록 원이 박혀 있었다. 그림에서 원을 지우고 그 자리를 코드에서 노선색으로 칠한다 |
| 6 | XML 외부 엔티티 허용 | 이 API는 HTTPS를 제공하지 않아(2026-08 확인) 평문으로 받는다. 기본 파서는 응답에 실린 DOCTYPE·외부 엔티티를 해석해 로컬 파일 읽기·내부 요청에 쓰일 수 있다 |

2번은 사용자가 "5시간이 아닌 것 같다"고 짚어 다시 계산하면서 드러났다.
기기 시각 00:20, 실제 다음 열차는 24:21(=00:21, 1분 뒤)이었다.

### 회귀 방지 — 아래는 다시 나타나서는 안 된다

이 회차에 실제로 나왔던 문제들이다. 노선도를 손볼 때마다 확인한다.

| # | 다시 나오면 안 되는 것 | 확인 방법 |
|---|------------------------|-----------|
| R-01 | 신정네거리에서 문래로 이어지는 선 | 2호선 신정지선. 신도림에서 갈라져야 한다 |
| R-02 | 하남시청에서 둔촌동으로 이어지는 선 | 5호선. 하남 방면과 마천 방면은 강동에서 갈린다 |
| R-03 | 용답에서 한양대로 이어지는 선 | 2호선 성수지선은 성수에 붙는다 |
| R-04 | 수인분당선 오이도·한대앞 구간 끊김 | 좌표가 없는 환승역은 같은 이름 역의 좌표를 빌려 쓴다 |
| R-05 | 고른 역 이름이 두 겹으로 뭉개짐 | 이름은 한 번만 그린다 |
| R-06 | 저장 목록 배지가 노선과 무관하게 초록 | 4호선은 파랑, 9호선은 베이지 |
| R-07 | 배지·삭제 버튼이 타원 | 정사각형 뷰로 두어 항상 원이다 |
| R-08 | 역 정보·시간표 화면이 초록 고정 | 고른 역의 노선색을 따른다 |
| R-09 | 자정 이후 편성이 목록에서 사라짐 | `24:54:00` 표기를 자정 이후로 환산한다 |
| R-10 | "곧 도착"이 더 늦은 열차를 가리킴 | 남은 시간이 짧은 순으로 고른다 |
| R-11 | 남은 시간이 멈춰 있음 | 1초마다 다시 계산한다 |
| R-12 | 뒤로가기 화살표 | 어느 화면에도 두지 않는다. 뒤로가기는 기기 버튼으로 |
| R-13 | 미지원 노선을 골라 빈 결과 | 안내만 하고 조회하지 않는다 |

전 노선 연결을 한 번에 검사하려면 노선별 최장 연결을 뽑아 보면 된다. 지선을 잘못 이으면
그 노선에서만 유난히 긴 연결이 나타난다(2026-08-22 기준 1~9호선 최장 9.1km, 1호선 평택–성환).

### 확인된 한계

- **`uiautomator dump` 가 이 앱의 결과 화면에서 실패한다**(`ERROR: could not get idle state`).
  남은 시간을 1초마다 갱신해 화면이 idle 상태가 되지 않기 때문이다. 갱신 범위를 시간
  표시로 좁혀도(`notifyItemRangeChanged` + payload) 마찬가지다. 이 화면은 스크린샷으로 검증했다.
- **APK 안에는 인증키가 들어 있다.** `BuildConfig` 문자열이라 `classes*.dex` 에서 찾을 수 있다.
  `local.properties` 방식은 키를 git 에서만 빼내는 것이고 APK 배포는 별개 문제다.

## 사전 조건

- `local.properties`에 `sdk.dir` (Android Studio가 자동 생성)
- `local.properties`에 유효한 `SEOUL_OPENAPI_KEY`
- Android 8.0(API 26) 이상 기기 또는 에뮬레이터
- 인터넷 연결

| TC-41 | 결과 화면 이탈 후 재진입 | 이전 조회 상태가 남아 있지 않다 | ✅ 재진입 시 검색 조건 초기화 확인 |

## 8. 설정 · 보안
