# 테스트 케이스 (TC)

실시간 지하철 도착 정보 앱 · 수동 검증 시나리오

> 이 문서는 **실행해야 할 검증 항목 목록**이다. 결과 열은 실제 기기/에뮬레이터에서
> 확인한 뒤 채운다. 프로젝트에 자동화된 테스트는 없다.

## 사전 조건

- `local.properties`에 유효한 `SEOUL_OPENAPI_KEY`가 설정되어 있을 것
- Android 8.0(API 26) 이상 기기 또는 에뮬레이터
- 인터넷 연결
