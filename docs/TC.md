# 테스트 케이스 (TC)

실시간 지하철 도착 정보 앱 · 검증 시나리오

## 검증 환경

| 항목 | 값 |
|------|-----|
| 실행일 | 2026-08-09 |
| 기기 | Android 11 (API 30) 에뮬레이터, 1080×2340 / 440dpi, Google APIs x86_64 |
| 빌드 | JDK 17 / AGP 7.4.2 / Gradle 7.6.4 / compileSdk 33 |
| 인증키 | **없음** — 유효한 `SEOUL_OPENAPI_KEY` 미보유 |

`./gradlew clean assembleDebug` 통과, `app-debug.apk` 생성 확인.

## 결과 요약

| 상태 | 개수 | 의미 |
|------|------|------|
| ✅ 통과 | 19 | 실행해서 기대 동작 확인 |
| ⛔ 차단 | 25 | 유효한 인증키가 있어야 실행 가능 |
| ➖ 참고 | 1 | 에뮬레이터 값이라 판정 기준으로 쓰지 않음 |

> ⛔ 항목은 **결함이 아니라 미실행**이다. `local.properties`의 `SEOUL_OPENAPI_KEY`에
> 유효한 키를 넣으면 전부 실행할 수 있다.

## 사전 조건

- `local.properties`에 `sdk.dir` (Android Studio가 자동 생성)
- `local.properties`에 유효한 `SEOUL_OPENAPI_KEY`
- Android 8.0(API 26) 이상 기기 또는 에뮬레이터
- 인터넷 연결

## 인증키를 넣고 재실행하려면

```properties
# local.properties — git에 올라가지 않는다
sdk.dir=C:/Users/<사용자>/AppData/Local/Android/Sdk
SEOUL_OPENAPI_KEY=발급받은_키
```

다시 빌드·설치하면 ⛔ 25건을 모두 실행할 수 있다.
